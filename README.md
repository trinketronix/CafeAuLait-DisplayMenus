## ☕ Overview

This project consists of clean, responsive web-based menu boards customized for **Café Au Lait**.

Because smart TVs or media players can sometimes suffer from web browser glitches, font rendering bugs, or network dropouts, the recommended workflow for maximum reliability is:
1. Edit the webpage template on your computer.
2. Take a high-resolution full-screen snapshot or export.
3. Crop/resize the image to the exact TV specs (**3260 × 1840 pixels**).
4. Load the image onto your TV screen (via USB drive, media player app, or digital signage software).

## 📺 Step-by-Step Guide: Creating Images for Your TV Screens

*(Written for non-tech users!)*

To make sure your menus look crisp and never go blank if the internet drops, follow these simple steps using any image editor (like **Photoshop**, **Canva**, **Paint.NET**, **GIMP**, or **Mac Preview**).

### 🛠️ What You Need:
* A web browser (Google Chrome or Microsoft Edge recommended)
* An image editing tool or screenshot tool
* A USB flash drive or TV screen media software

---

### Step 1: Edit Your Menu Items
1. Open the file you want to change (e.g., `CafeAuLait-Barista-Display.html`) in a text editor like **Notepad** (Windows) or **TextEdit** (Mac).
2. Find the item name or price you want to change (e.g., change `$4.50` to `$4.75`).
3. Save the file (`Ctrl + S` on Windows, `Cmd + S` on Mac).
4. Refresh the webpage in your browser to see your changes!

---

### Step 2: Capture a High-Quality Screenshot
1. Put your web browser into **Full Screen Mode** by pressing **F11** (Windows) or **Control + Command + F** (Mac).
2. Take a high-resolution screenshot:
    * **Windows:** Press `PrtScn` (Print Screen) or use the **Snipping Tool** (`Win + Shift + S`).
    * **Mac:** Press `Shift + Command + 4` and capture the screen area.
    * *Pro Tip:* You can also use Chrome's developer tools or a browser extension like "Full Page Screen Capture" for exact pixel-perfect captures.

---

### Step 3: Resize & Crop in Your Image Editor (CRITICAL STEP)
Your TV screens require a specific size and ratio so that text is crystal clear and doesn't stretch or distort.

1. Open your saved screenshot in your favorite image editing app (Photoshop, Canva, Paint.NET, Photopea, etc.).
2. Set your Canvas/Crop tool to the **16:9 Aspect Ratio**.
3. Resize or crop the image to the exact resolution:
    * **Width:** `3260 pixels`
    * **Height:** `1840 pixels`
4. **Export/Save As:**
    * File Format: **PNG** (recommended for sharp text) or high-quality **JPEG** (90%+ quality).
    * Name your file clearly, like `TV_Left_CoffeeMenu_v1.png`.

---

### Step 4: Display on Your Cafe TV
1. Copy the exported `3260 x 1840` image file onto a USB flash drive.
2. Insert the USB drive into your TV monitor or digital sign player.
3. Set your TV built-in media player to view the image in **Full Screen / Fit to Screen** mode (disable screen saver/sleep timer).

## 📐 Resolution & Aspect Ratio Requirements

To ensure zero distortion and perfect clarity across your Café Au Lait display monitors, always adhere to these exact specifications:

| Parameter | Specification |
| :--- | :--- |
| **Aspect Ratio** | `16:9` (Standard Widescreen TV format) |
| **Width** | `3260 pixels` |
| **Height** | `1840 pixels` |
| **Color Space** | RGB / sRGB |
| **File Format** | `.png` (best for crisp text) or `.jpg` / `.jpeg` |
| **DPI / Resolution** | 72 DPI (screen standard) or higher |

## 🎨 Tips for Great Display Aesthetics

- **Contrast is King:** Keep light text on dark backgrounds or vice-versa so customers standing in line can read the menu from 10–15 feet away.
- **Keep Font Sizes Large:** Main drink titles should be easily legible at a quick glance.
- **High-Res Images:** If adding food photos to the templates, ensure they are high-resolution so they don't look blurry at 3260x1840.
- **Double-Check Prices:** Always preview your exported `3260 x 1840` image on a monitor before copying it to the TV flash drive.
